# Sistema de Gestão de Estudos

Sistema de linha de comando desenvolvido em Python para organizar matérias, notas e tarefas de estudo.

## Sobre o projeto

Este projeto foi desenvolvido como parte da minha formação complementar em Ciência da Computação, com o objetivo de aplicar na prática os fundamentos de programação estudados na Etapa 1.

O sistema permite cadastrar matérias, registrar notas, calcular médias, criar tarefas e acompanhar o status das atividades.

Os dados são armazenados localmente em um arquivo JSON, permitindo que as informações continuem disponíveis mesmo depois que o programa é encerrado.

## Funcionalidades

- Cadastrar matérias
- Listar matérias
- Registrar notas
- Calcular médias
- Adicionar tarefas
- Listar tarefas
- Concluir tarefas
- Salvar dados em arquivo JSON
- Carregar dados automaticamente ao iniciar
- Menu interativo no terminal
